நவீன ஆட்டோமேஷன் & ஐஓடி தீர்வுகள்

உங்கள் நீர் மேலாண்மையை மிகவும் எளிமையாகவும், பாதுகாப்பாகவும் மாற்ற எங்களது அதிநவீன வாட்டர் லெவல் கண்ட்ரோலர்களைப் பயன்படுத்துங்கள்.

எங்கள் வாட்டர் லெவல் கண்ட்ரோலர் மாடல்கள்

Basic Version

AWLCP 1.0

நம்பகமான பேசிக் வெர்ஷன் வாட்டர் லெவல் கண்ட்ரோலர். இதில் பிரதானமாக மோட்டார் பாதுகாப்பிற்கான ட்ரைடன் கண்ட்ரோல் (Dry Run Protection) சிறப்பம்சமாக உள்ளது.

WiFi Model

AWLCW 1.0
